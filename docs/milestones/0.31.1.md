# 0.31.1 - Identidad visual / Visual identity

## Español

### Objetivo

Dar a Zar Agent Session Ops una marca reconocible sin alterar el flujo operativo
del producto ni convertir el dashboard en una superficie promocional.

### Entrega

- Símbolo original con fondo transparente, basado en capas de sesiones y una
  conexión en forma de Z que expresa continuidad del ciclo de vida.
- Activo central en `dashboard/public/brand/zar-agent-session-ops.png`.
- Logotipo visible en los README español e inglés.
- Barra superior del dashboard con símbolo y nombre completo de producto.
- Favicon y color de tema para la pestaña del navegador.
- Composición móvil que conserva el símbolo y reduce el texto cuando falta
  espacio.

### Límites deliberados

- No se cambia la paleta Material, la estructura del dashboard ni sus flujos.
- No se añade una dependencia de iconos o branding.
- El símbolo no contiene texto incrustado para conservar legibilidad en tamaños
  pequeños y facilitar su reutilización.

### Verificación

- Transparencia RGBA comprobada en el PNG final.
- 28 pruebas Python y 7 pruebas Angular.
- Build Angular de producción y auditoría npm.
- Detector de calidad visual sobre los archivos modificados.
- Stack Docker 0.31.1 y representación real comprobados en loopback.

## English

### Goal

Give Zar Agent Session Ops a recognizable identity without changing the
product's operational flow or turning the dashboard into a promotional surface.

### Delivery

- Original transparent symbol based on layered sessions and a Z-shaped
  connection that expresses lifecycle continuity.
- Canonical asset at `dashboard/public/brand/zar-agent-session-ops.png`.
- Logo displayed in both Spanish and English README files.
- Dashboard toolbar with the symbol and complete product name.
- Browser-tab favicon and theme color.
- Mobile composition that keeps the symbol while reducing text when space is
  constrained.

### Deliberate limits

- The Material palette, dashboard structure, and operational flows remain
  unchanged.
- No icon or branding dependency is added.
- The symbol embeds no text, preserving small-size legibility and reuse.

### Verification

- RGBA transparency checked in the final PNG.
- 28 Python tests and 7 Angular tests.
- Production Angular build and npm audit.
- UI quality detector over the modified files.
- Docker stack 0.31.1 and real rendering checked on loopback.
