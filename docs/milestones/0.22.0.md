# 0.22.0 - Relevo visible sin modelo / Visible model-free handoff

Fecha / Date: 2026-08-09

## Español

### Objetivo

Completar el flujo de continuidad desde la ficha operativa. El usuario debe
poder obtener contexto portátil aunque no tenga un modelo Ollama instalado, leer
el resultado dentro de la web y sacarlo sin abrir herramientas externas.

### Resultado

- `Generar relevo` crea Markdown bajo demanda desde la sesión exacta identificada
  por `record_key`.
- El modo base no necesita Ollama: combina metadatos, objetivo conocido, último
  resultado del asistente y una petición posterior cuando existe.
- Cada fragmento de conversación queda limitado a 800 caracteres y escapado
  antes de renderizarse.
- El documento declara que las decisiones técnicas no se infieren en modo base,
  en vez de inventarlas.
- La ficha renderiza el Markdown como HTML legible y permite copiarlo o descargar
  `session-handoff.md`.
- El comando CLI `handoff --model` conserva el flujo Ollama existente para una
  síntesis semántica opcional.

### Contrato y privacidad

- La API lee como máximo los últimos 24.000 caracteres admitidos por el extractor
  existente y no persiste la transcripción ni el relevo.
- La respuesta no contiene la ruta del JSONL ni `source_entry`.
- Generar, copiar o descargar no modifica la sesión, SQLite ni el inventario.
- El modo base no realiza llamadas de red externas ni intenta descargar modelos.
- Si la fuente no contiene mensajes compatibles, se entrega un relevo de
  metadatos y se declara esa limitación.

### Verificación

- 21 pruebas Python superadas, incluido el relevo base sin Ollama, el escape de
  HTML y el endpoint sobre la clave exacta.
- 7 pruebas Angular superadas, incluido el renderizado seguro y el enlace de
  descarga desde la ficha.
- Build Angular de producción completado sin superar el presupuesto.
- `npm audit --audit-level=moderate`: 0 vulnerabilidades.
- Detector Impeccable sobre HTML, SCSS y TypeScript: 0 hallazgos.
- Stack Docker 0.22 construido con API saludable y dashboard disponible en
  `http://127.0.0.1:4200`.
- Navegador real validado generando y visualizando un relevo; ninguna sesión ni
  decisión de ciclo de vida fue modificada.

### Límites conocidos

- El modo base no puede deducir decisiones ni tareas semánticas que no estén en
  el último contexto explícito. Para esa síntesis sigue disponible el CLI Ollama.
- Las entradas Claude Code registradas sin transcripción producen un relevo de
  metadatos hasta disponer de fixtures reales para ampliar el adaptador.

## English

### Goal

Complete the continuation flow from the operational record. The user must be
able to obtain portable context without an installed Ollama model, read the
result inside the web interface, and take it away without an external viewer.

### Result

- `Generate handoff` creates Markdown on demand for the exact session identified
  by `record_key`.
- Base mode needs no Ollama model: it combines metadata, known objective, latest
  assistant outcome, and a later request when one exists.
- Each conversation excerpt is capped at 800 characters and escaped before it is
  rendered.
- The document states that technical decisions are not inferred in base mode
  instead of inventing them.
- The record renders Markdown as readable HTML and can copy it or download
  `session-handoff.md`.
- The existing CLI `handoff --model` flow remains available for optional Ollama
  semantic synthesis.

### Contract and privacy

- The API reads at most the final 24,000 characters accepted by the existing
  extractor and persists neither transcript nor handoff.
- The response contains neither the JSONL path nor `source_entry`.
- Generating, copying, or downloading changes neither the session, SQLite, nor
  the inventory.
- Base mode makes no external network call and never attempts to pull a model.
- When the source has no compatible messages, a metadata-only handoff is returned
  and explicitly states that limitation.

### Verification

- 21 Python tests passed, including model-free base generation, HTML escaping,
  and the exact-record endpoint.
- 7 Angular tests passed, including safe rendering and the record download link.
- Production Angular build completed within budget.
- `npm audit --audit-level=moderate`: 0 vulnerabilities.
- Impeccable detector over HTML, SCSS, and TypeScript: 0 findings.
- Docker 0.22 stack built with a healthy API and dashboard available at
  `http://127.0.0.1:4200`.
- Real-browser validation generated and displayed a handoff; no session or
  lifecycle decision was modified.

### Known limits

- Base mode cannot infer semantic decisions or tasks absent from the latest
  explicit context. The Ollama CLI remains available for that synthesis.
- Claude Code registry entries without transcripts produce metadata-only
  handoffs until real fixtures support a broader adapter.
