# 0.25.0 - Ficha de actividad accionable / Actionable activity record

Fecha / Date: 2026-08-11

## Español

### Resultado

- La ficha operativa carga bajo demanda el objetivo, el último resultado del
  asistente, cualquier petición posterior y los seis fragmentos más recientes.
- La siguiente acción se decide con reglas visibles y deterministas: responder
  una petición pendiente, revisar una tarea activa sin cierre o verificar el
  repositorio antes de continuar o archivar.
- `GET /api/sessions/{record_key}/activity` trabaja sobre la sesión exacta y
  devuelve un contrato JSON estable para la interfaz.
- Cada fragmento se limita a 500 caracteres. La respuesta no contiene rutas y
  el transcript no se copia a SQLite.
- La vista incluye estados de carga, fallo y ausencia de mensajes legibles.

### Verificación

- 25 pruebas Python superadas, incluido el contrato de actividad y la omisión
  de rutas fuente.
- 7 pruebas Angular superadas, incluida la lectura de la petición pendiente y
  su siguiente acción.
- Build Angular de producción dentro del presupuesto y auditoría npm sin
  vulnerabilidades de nivel moderado o superior.
- Detector Impeccable y `git diff --check` sin hallazgos.
- Stack Docker 0.25 saludable y flujo revisado en navegador real.

## English

### Result

- The operational record loads the objective, latest assistant outcome, any
  later request, and the six most recent excerpts on demand.
- The next action follows visible deterministic rules: answer a pending request,
  review an active task without a closing event, or verify the repository before
  continuing or archiving.
- `GET /api/sessions/{record_key}/activity` targets the exact session and returns
  a stable JSON contract for the interface.
- Each excerpt is capped at 500 characters. The response includes no paths, and
  the transcript is not copied into SQLite.
- The view includes loading, failure, and no-readable-message states.

### Verification

- 25 Python tests passed, including the activity contract and source-path
  omission.
- 7 Angular tests passed, including pending-request and next-action rendering.
- Production Angular build stayed within budget, and npm audit reported no
  moderate-or-higher vulnerabilities.
- Impeccable detector and `git diff --check` reported no findings.
- Docker 0.25 stack was healthy, and the flow was reviewed in a real browser.
