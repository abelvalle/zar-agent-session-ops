# 0.31.0 - Continuación directa en Codex / Direct Codex continuation

## Español

### Objetivo

Convertir el relevo mínimo visible en una continuación accionable: abrir una
tarea nueva en Codex, apuntar al repositorio correcto y precargar el contexto
sin arrastrar la conversación original.

### Entrega

- La ficha muestra **Abrir nueva tarea en Codex** cuando el relevo está listo.
- El enlace `codex://threads/new` incluye el relevo como `prompt` codificado y,
  cuando el repositorio es una ruta absoluta, lo incluye como `path`.
- Codex abre una tarea local nueva y deja el texto en el compositor. Zar Agent
  Session Ops no lo envía ni inicia ejecución alguna.
- Copiar Markdown y descargar `.md` siguen disponibles como alternativas.
- La implementación sigue el contrato publicado en la
  [documentación oficial de comandos de OpenAI](https://learn.chatgpt.com/docs/reference/commands).

### Límites deliberados

- El sistema operativo debe tener registrado el esquema `codex://` mediante la
  aplicación de escritorio.
- No existe un envío automático: el usuario revisa y confirma el mensaje en la
  nueva tarea.
- Una sesión sin ruta absoluta abre la tarea con el relevo, pero sin seleccionar
  un workspace potencialmente incorrecto.

### Verificación

- 28 pruebas Python, incluidas las regresiones del contrato API.
- 7 pruebas Angular, incluida la codificación exacta de `prompt` y `path`.
- Build Angular de producción, auditoría npm y validación visual en navegador.
- Stack Docker 0.31 comprobado en loopback y flujo visible validado en navegador.

## English

### Goal

Turn the visible minimal handoff into an actionable continuation: open a new
Codex task, target the correct repository, and prefill context without carrying
the original conversation forward.

### Delivery

- The record shows **Open new task in Codex** when the handoff is ready.
- The `codex://threads/new` link includes the encoded handoff as `prompt` and,
  when the repository is an absolute path, includes it as `path`.
- Codex opens a new local task and leaves the text in the composer. Zar Agent
  Session Ops neither sends it nor starts execution.
- Copy Markdown and `.md` download remain available as fallbacks.
- The implementation follows the contract in the
  [official OpenAI commands documentation](https://learn.chatgpt.com/docs/reference/commands).

### Deliberate limits

- The operating system must have the `codex://` scheme registered by the
  desktop application.
- There is no automatic submission: the user reviews and confirms the message
  in the new task.
- A session without an absolute repository path opens the task with its handoff
  but does not select a potentially incorrect workspace.

### Verification

- 28 Python tests, including API contract regressions.
- 7 Angular tests, including exact `prompt` and `path` encoding.
- Production Angular build, npm audit, and visual browser validation.
- Docker stack 0.31 checked on loopback and the visible flow validated in a
  browser.
