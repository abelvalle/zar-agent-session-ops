# 0.28.0 - Gestión de fuentes e importación ChatGPT / Source management and ChatGPT import

Fecha / Date: 2026-08-11

## Español

### Contrato oficial comprobado

La [documentación oficial de OpenAI](https://help.openai.com/en/articles/7260999-how-do-i-export-my-chatgpt-history-and-data)
indica que la exportación se solicita desde `Settings → Data controls`, llega
como ZIP y contiene el historial de chats junto con otros datos de la cuenta.

### Resultado

- `GET /api/sources` muestra Codex, Claude Code, ChatGPT y OpenCode con estado y
  recuento, sin devolver rutas.
- La interfaz acepta `.zip` y `.json`, primero ejecuta una vista previa y muestra
  hasta diez títulos y sus eventos.
- La vista previa no cambia SQLite ni conserva el archivo. La importación exige
  la confirmación literal `IMPORT_CHATGPT`.
- La carga se limita a 100 MiB y los JSON de conversaciones expandidos a 500
  MiB para reducir el riesgo de archivos comprimidos abusivos.
- Tras confirmar, la aplicación guarda una copia con nombre derivado de su hash
  en su almacenamiento local y conserva solo metadatos en SQLite. Esto permite
  que actividad y relevos sigan funcionando tras reiniciar.
- Importaciones repetidas se deduplican por contenido y conversación.

### Verificación

- 26 pruebas Python superadas, incluida vista previa sin persistencia,
  confirmación obligatoria, copia gestionada e inventario de fuentes.
- 7 pruebas Angular superadas, incluido el envío binario en dos fases y la
  recarga del inventario tras confirmar.
- Build Angular de producción, auditoría npm, detector Impeccable y
  `git diff --check` sin hallazgos.
- Stack Docker 0.28 saludable y flujo de carga validado en navegador con una
  exportación sintética, sin usar conversaciones del usuario.

## English

### Verified official contract

[Official OpenAI documentation](https://help.openai.com/en/articles/7260999-how-do-i-export-my-chatgpt-history-and-data)
states that exports are requested under `Settings → Data controls`, arrive as a
ZIP and include chat history plus other account data.

### Result

- `GET /api/sources` shows Codex, Claude Code, ChatGPT, and OpenCode with status
  and counts while returning no paths.
- The UI accepts `.zip` and `.json`, first runs a preview, and shows up to ten
  titles and event counts.
- Preview changes neither SQLite nor stored files. Import requires the literal
  `IMPORT_CHATGPT` confirmation.
- Upload size is capped at 100 MiB and expanded conversation JSON at 500 MiB to
  reduce abusive archive risk.
- After confirmation, the application stores a hash-named managed local copy
  and keeps metadata only in SQLite. Activity and handoffs therefore remain
  available after restart.
- Repeated imports are deduplicated by content and conversation.

### Verification

- 26 Python tests passed, including non-persistent preview, required
  confirmation, managed copy, and source inventory.
- 7 Angular tests passed, including two-phase binary upload and inventory reload
  after confirmation.
- Production Angular build, npm audit, Impeccable detector, and
  `git diff --check` reported no findings.
- Docker 0.28 stack was healthy, and the upload flow was validated in a browser
  with a synthetic export rather than user conversations.
