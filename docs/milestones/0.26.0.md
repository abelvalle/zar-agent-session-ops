# 0.26.0 - Flujo completo de decisión / Complete decision flow

Fecha / Date: 2026-08-11

## Español

### Resultado

- Cada ficha muestra `Revisar → Entender → Decidir` como un flujo único, junto
  a la ficha de actividad y las confirmaciones de ciclo de vida.
- `Revisar` expone el número de eventos y el último tipo de evento terminal.
- `Entender` usa el objetivo y prioriza una petición pendiente sobre el último
  resultado; si la fuente no está disponible, limita expresamente la decisión a
  los metadatos.
- `Decidir` explica qué regla aplica. Un posible bloqueo tiene prioridad sobre
  retención; en ausencia de señales propone continuar con un relevo mínimo.
- Las acciones conducen al relevo, a la confirmación reversible de falso bloqueo
  o a la previsualización del archivado. Ninguna omite sus confirmaciones.

### Verificación

- 25 pruebas Python superadas.
- 7 pruebas Angular superadas; recorren continuidad, descarte de señal y vista
  previa de archivado desde el nuevo flujo.
- Build Angular de producción, auditoría npm, detector Impeccable y
  `git diff --check` sin hallazgos.
- Stack Docker 0.26 saludable y flujo revisado en navegador real sin errores de
  consola.

## English

### Result

- Every record presents `Review → Understand → Decide` as one flow beside the
  activity record and lifecycle confirmations.
- `Review` shows event count and the latest terminal event type.
- `Understand` uses the objective and prioritizes a pending request over the
  latest outcome; when the source is unavailable, it explicitly limits the
  decision to metadata.
- `Decide` explains which rule applies. A possible block takes priority over
  retention; when no signal exists, it proposes continuing with a minimal
  handoff.
- Actions lead to the handoff, reversible false-block confirmation, or archive
  preview. None bypasses its confirmation step.

### Verification

- 25 Python tests passed.
- 7 Angular tests passed, covering continuation, signal dismissal, and archive
  preview from the new flow.
- Production Angular build, npm audit, Impeccable detector, and
  `git diff --check` completed without findings.
- Docker 0.26 stack was healthy, and the flow was reviewed in a real browser
  without console errors.
