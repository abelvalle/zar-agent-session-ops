# 0.5.0 - Importación ChatGPT / ChatGPT import

## Español

### Objetivo

Incorporar conversaciones de ChatGPT sin scraping, cookies, automatización del
navegador ni acceso a bases privadas. La única entrada admitida es una
exportación solicitada por el propietario de la cuenta.

### Implementación

- Acepta el ZIP oficial, `conversations.json`, archivos numerados y directorios
  que los contengan.
- Conserva en SQLite solo identificador, título, fechas, tamaño y ubicación del
  archivo fuente.
- Mantiene Codex y ChatGPT en el mismo inventario sin colisiones aunque varias
  conversaciones procedan del mismo JSON.
- Extrae bajo demanda la rama actual de mensajes usuario/asistente para Ollama.
- Migra automáticamente el esquema `0.4.x` y preserva sus registros Codex.
- Una nueva importación sustituye solo los registros `agent = chatgpt`.

### Verificación

- 5 pruebas aprobadas.
- Fixture ZIP con dos conversaciones que comparten `conversations.json`.
- Extracción ordenada de mensajes usuario/asistente.
- Migración `0.4.x` verificada conservando un registro Codex existente.
- `git diff --check` sin errores.

### Límites conocidos

- No había una exportación personal disponible para validación real.
- OpenAI documenta el proceso y el nombre `conversations.json`, no su esquema
  interno; el parser es experimental.
- El parser carga cada JSON completo con la biblioteca estándar. Se sustituirá
  por streaming solo si exportaciones reales demuestran un problema de memoria.
- No existe sincronización en vivo: hay que solicitar e importar una nueva
  exportación para actualizar el inventario.

## English

### Goal

Bring ChatGPT conversations into the inventory without scraping, cookies,
browser automation, or private database access. The only accepted input is an
export requested by the account owner.

### Implementation

- Accepts the official ZIP, `conversations.json`, numbered files, and
  directories containing them.
- Stores only identifier, title, dates, size, and source location in SQLite.
- Keeps Codex and ChatGPT in one inventory without collisions when several
  conversations share the same JSON file.
- Extracts the current user/assistant message branch for Ollama on demand.
- Automatically migrates `0.4.x` while preserving existing Codex records.
- A new import replaces only rows where `agent = chatgpt`.

### Verification

- 5 tests passed.
- ZIP fixture with two conversations sharing `conversations.json`.
- Ordered user/assistant message extraction.
- `0.4.x` migration verified while preserving an existing Codex row.
- `git diff --check` passed.

### Known limits

- No personal export was available for real-world validation.
- OpenAI documents the process and `conversations.json` filename, not its
  internal schema; the parser is experimental.
- The parser loads each JSON in full with the standard library. Streaming will
  be added only if real exports demonstrate a memory problem.
- This is not live synchronization: request and import a new export to refresh
  the inventory.
