# 0.27.0 - Política y mantenimiento web / Web policy and maintenance

Fecha / Date: 2026-08-11

## Español

### Resultado

- `GET|PUT /api/policy` consulta y actualiza `archive_after_days` y
  `blocked_after_hours` con límites explícitos.
- Al guardar se reescribe atómicamente la configuración y se conserva
  `archive_dir`; la interfaz no permite elegir una ruta arbitraria.
- `POST /api/maintenance/preview` recalcula candidatas de retención y señales de
  bloqueo visibles. El contrato fija `mode: dry_run` y no mueve archivos.
- Cada simulación guarda en SQLite su fecha, política y recuentos.
  `GET /api/maintenance/history` recupera las diez últimas.
- El dashboard actualiza las colas tras guardar y muestra formulario, resultado,
  errores y un historial legible.

### Verificación

- 25 pruebas Python superadas, incluidas validación, persistencia de política,
  simulación y recuperación de historial.
- 7 pruebas Angular superadas, incluido el formulario completo y el recibo
  visible que confirma que ningún archivo se movió.
- Build Angular de producción, auditoría npm, detector Impeccable y
  `git diff --check` sin hallazgos.
- Stack Docker 0.27 saludable y simulación verificada en navegador real sin
  aplicar cambios destructivos.

## English

### Result

- `GET|PUT /api/policy` reads and updates `archive_after_days` and
  `blocked_after_hours` with explicit bounds.
- Saving atomically rewrites configuration while preserving `archive_dir`; the
  UI cannot select an arbitrary path.
- `POST /api/maintenance/preview` recalculates retention candidates and visible
  blocking signals. Its contract fixes `mode: dry_run` and moves no files.
- Every preview stores its date, policy, and counts in SQLite.
  `GET /api/maintenance/history` returns the latest ten.
- The dashboard refreshes queues after saving and shows a form, result, errors,
  and readable history.

### Verification

- 25 Python tests passed, including validation, policy persistence, preview,
  and history retrieval.
- 7 Angular tests passed, including the complete form and visible receipt
  confirming that no file was moved.
- Production Angular build, npm audit, Impeccable detector, and
  `git diff --check` reported no findings.
- Docker 0.27 stack was healthy, and a real-browser preview was verified without
  applying destructive changes.
