# 0.4.0 - Inventario Codex completo / Complete Codex inventory

## Español

### Objetivo

Inventariar el estado local de Codex Desktop, CLI y VS Code usando solamente
fuentes de sesión legibles y evitando dependencias sobre el esquema SQLite
interno de la aplicación.

### Implementación

- `CODEX_HOME` pasa a ser la fuente predeterminada.
- `sessions/` se clasifica como activo y `archived_sessions/` como archivado.
- `session_index.jsonl` aporta el nombre visible de la tarea.
- `session_meta` aporta origen, repositorio y tipo de hilo.
- SQLite incorpora `status`, `title`, `origin` y `thread_source` mediante una
  migración compatible con `0.3.x`.
- Las políticas ignoran sesiones ya archivadas.

### Verificación

- 4 pruebas unitarias aprobadas.
- Migración probada desde el esquema SQLite de `0.3.x`.
- Inventario real: 58 activas, 403 archivadas y 416 nombres de tarea.
- `git diff --check` sin errores.

### Límite conocido

La versión no lee `state_*.sqlite`; cualquier metadato que solo exista allí se
omite deliberadamente para no depender de una base privada y versionada.

## English

### Goal

Inventory local Codex Desktop, CLI, and VS Code state using readable session
sources only, without depending on the application's internal SQLite schema.

### Implementation

- `CODEX_HOME` is now the default source.
- `sessions/` is classified as active and `archived_sessions/` as archived.
- `session_index.jsonl` supplies the visible task name.
- `session_meta` supplies origin, repository, and thread source.
- SQLite gains `status`, `title`, `origin`, and `thread_source` through a
  migration compatible with `0.3.x`.
- Policies ignore sessions already archived by Codex.

### Verification

- 4 unit tests passed.
- Migration tested from the `0.3.x` SQLite schema.
- Real inventory: 58 active, 403 archived, and 416 task names.
- `git diff --check` passed.

### Known limit

Version `0.4.0` does not read `state_*.sqlite`; metadata available only there is
deliberately omitted to avoid depending on a private, versioned database.
